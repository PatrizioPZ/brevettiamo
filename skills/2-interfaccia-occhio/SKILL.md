# Competenza: UI Front-End e Funzione Occhio Password
Attivati ogni volta che viene generato un form di input per password o dati sensibili.

## Regole Tassative di Sviluppo:
1. Ogni campo password deve avere un'icona (SVG o carattere) raffigurante un "occhio".
2. Implementa il codice JavaScript nativo per cambiare l'attributo del campo da `type="password"` a `type="text"` al clic dell'utente.
3. Assicurati che lo stile CSS non nasconda l'icona e che sia usabile su dispositivi mobile.
