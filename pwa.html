2 Caratteristiche

• Cifratura AES-256 GCM

Ogni file cifrato individualmente con chiave derivata dalla tua password. Nessuno puo accedere.

• Storage Locale

I file cifrati restano sul dispositivo in IndexedDB. Accesso offline garantito.

• Upload Universale

Carica da PC, iPad, Android. Touch, drag&drop, selezione file. Ogni formato.

• Esporta / Importa

Trasferisci file cifrati tra dispositivi. Stessa password per decifrare ovunque.

• Nessuno Store

Installazione diretta come PWA. Zero commissioni. Zero dipendenze.
